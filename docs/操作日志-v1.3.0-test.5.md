# 操作日志 · v1.3.0-test.5 / test.6（电视端小屏模式）

- 日期：2026-11-24
- 版本：`1.3.0-test.5`（versionCode 9）
- 范围：电视端播放页；手机端逻辑不变
- 基线：`1.3.0-test.4`（去广告测试版）

## 一、需求

1. 电视端快进时显示视频进度
2. 全屏退出后显示剧集介绍、集数、视频源、测速信息
3. 大屏缩小为小屏播放
4. 全屏退出后添加全屏键
5. 最近播放界面直接进入全屏

## 二、改了什么

### 1. 快进进度提示（`components/SeekingBar.tsx`、`stores/playerStore.ts`）

原状态：遥控器按左右键只调 `seek()`，画面无任何反馈；长按每 200ms 直接 `setPositionAsync`，
播放器被反复打断，观感很卡。

现状态：

| 操作 | 行为 |
|---|---|
| 单击左右 | 跳 20 秒，中央卡片显示「快进/快退 20 秒 + 时间 + 进度条」，800ms 后收起 |
| 长按左右 | 进入预览态，每 200ms 累加 10 秒，画面进度条连续走；松手才真正跳转 |
| 4 秒无事件 | 兜底当作松手，自动提交并收起（部分电视长按不发松手事件） |

- `playerStore` 新增 `seekDeltaMillis`，`seekBy` 写入实际位移，`beginSeek`/`commitSeek` 归零。
- `SeekingBar` 新增 `sources`（按 seek 来源过滤）与 `variant`（电视端放大字号），
  避免与控件里的进度条叠成重影。

### 2. 电视端小屏模式（`components/TVPlayerInfoPanel.tsx`）

新增组件，布局：

```
┌──────────────────────────────────────────────────────┐
│ ← 片名 · 第 3 集                            [全屏]   │ 64
├──────────────────────────┬───────────────────────────┤
│      16:9 小窗（继续播）   │ 剧情简介                   │
│                          │ 播放源（5）    [重新测速]   │
│  片名 / 年份·类型·线路·速度 │  源A  12集 1080P 2.1MB/s  │
│  00:12:30 ─────●── 45:00 │  源B  12集   未测速        │
│  [上一集][播放][下一集]    │ 播放列表 共 12 集          │
│                          │  [1][2][3][4][5][6]…      │
└──────────────────────────┴───────────────────────────┘
```

- 视频层不卸载，只改尺寸，所以缩小/放大不重新加载。
- 所有按钮都带遥控器焦点态（白框 + 高亮底色），方向键移动、确定键触发。
- 右上角「全屏」按钮 `hasTVPreferredFocus`，进小屏后按确定键立刻回大屏。
- 切源保留当前播放进度（`position: status.positionMillis`）。

### 3. 入口与返回（`app/play.tsx`、`components/PlayerControls.tsx`）

| 场景 | 行为 |
|---|---|
| 电视端进入播放页 | 一律大屏满屏（含从「最近播放」点进来） |
| 大屏控件「缩小」按钮 | 进小屏 |
| 大屏按遥控器返回 | 进小屏 |
| 小屏按遥控器返回 | 退出播放页 |

- `useTVRemoteHandler(enabled)`：小屏模式传 `false`，方向键让给焦点导航，不会误触发快进。
- 首帧按全屏排版（`layoutReady`），避免先渲染小屏再跳全屏的闪烁。
- 720p 电视逻辑分辨率可能只有 960×540：`compact` 档位收紧字号与间距；
  内容仍放不下时信息区上移并加半透明底色。

## 三、验证

- `npx tsc --noEmit`：业务代码 0 错误（仅 `utils/__tests__/DeviceUtils.test.ts` 等既有测试类型告警）。
- `npx jest`：62 通过 / 1 既有快照失败（`ThemedText` 深色模式快照，与本次改动无关）。
- APK 内 `lib/` 只含目标 ABI，so 数量与上一版一致（32 位 48 个 / 64 位 48 个）。

## 四、真机验证清单

1. 大屏按左右键：中央是否出现「快进 20 秒 + 进度条」，1 秒内消失。
2. 长按右键 2 秒：进度条连续走，松手后跳到目标位置，画面不卡顿。
3. 大屏点「缩小」：视频是否原地缩到左上角并继续播放，右侧是否出现简介/线路/集数。
4. 小屏按「全屏」：是否立即铺满，播放不中断。
5. 小屏切线路 / 切集：进度是否保留、画面是否正常。
6. 首页「最近播放」点进去：是否直接大屏播放，而不是小屏。
7. 小屏按返回：是否退出播放；大屏按返回：是否先回小屏。

## 六、test.6 追加（小窗画面可聚焦）

用户反馈：小屏画面不能被遥控器选中，希望能点画面直接放大。

- 在小窗视频区叠一层透明 `Pressable`（`focusable`），几何位置与视频层一致。
- 聚焦时显示 3px 白色边框 + 画面中央「按确定键全屏」胶囊提示，按确定键执行 `enterFullscreen()`。
- 右上角「全屏」按钮保持原样，仍然带 `hasTVPreferredFocus`，进小屏后按确定键即可回大屏。
- 小屏模式 `useTVRemoteHandler(false)` 未变，方向键仍只用于移动焦点，不会误触发快进。
- 版本 `1.3.0-test.6`（versionCode 10）。
