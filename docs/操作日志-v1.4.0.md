# 操作日志 · v1.4.0（多用户管理）

> 版本：`1.4.0` / `versionCode 13`
> 日期：2026-11-24
> 产物：手机端 64 位（arm64-v8a）、电视端 32 位（armeabi-v7a）

## 一、需求

- 电视端首页右上角的「退出」改为「用户管理」，点开后可**切换用户**或**退出当前账户**。
- 手机端在设置里新增「用户管理」，点开后同样能切换用户或退出当前账户。

「多用户管理」意味着本机要记住多个账号，而不是只保留最后一次登录的那一个。

## 二、改动

### 1. 账号档案（新增 `services/accountProfiles.ts`）

| 能力 | 说明 |
|---|---|
| `getAll()` | 读取全部账号；列表为空且有旧版单账号凭据时自动迁移成一条档案 |
| `upsert(username, password)` | 新增/更新账号并设为当前，同名（忽略大小写）只更新密码 |
| `setActive(id)` | 切换当前账号，同步写 `LoginCredentialsManager` |
| `clearActive()` | 退出当前账号：从列表移除 + 清空启动凭据 |

档案字段：`id`（用户名小写）、`username`、`password`、`server`、`addedAt`、`lastUsedAt`。

`LoginCredentialsManager` 保持「只存当前生效账号」的语义，启动流程（bootStore）继续读它，
不感知多账号的存在 —— 这样切换账号只是换一份凭据，启动链路零改动。

### 2. 切换流程（新增 `stores/userStore.ts`）

```
选中账号 → api.login(用户名, 密码)
        → 成功：setActive(id) → 清首页缓存 → 重拉收藏 / 播放记录 → 提示「已切换到 xxx」
        → 失败：把当前凭据还原成切换前的账号，提示原因，不动界面数据
```

切换/新增成功后统一调用 `applyBootSession(true)`，复用 5 秒登录态有效期，
避免紧接着的首页请求又打一轮校验。

### 3. 退出流程

1. `authStore.logout()`：调 `/api/logout`（失败也继续）→ 清 `authCookies` → 清本机账号档案；
2. `userStore` 清空收藏、首页、内容缓存；
3. 弹出登录框；手机端如果是在设置页退出，先 `router.replace("/")`，否则登录框不会显示。

### 4. 界面

- `components/UserManagementModal.tsx`：两端共用面板。
  - 账号列表：首字母头像、用户名、「当前」徽标、上次使用时间；
  - 底部 `添加账号` / `退出当前账户`；退出带二次确认（取消默认选中，防止遥控器误触）；
  - 添加账号为内联表单（用户名 + 密码 + 登录并保存）；
  - 点卡片外的空白关闭；`onRequestClose` 处理遥控器返回键；
  - 电视端全部控件 `focusable`，焦点高亮边框；列表为空时首选焦点给「添加账号」。
- 电视端 `app/index.tsx`：右上角 `LogOut` 图标 → `Users` 图标，点击打开面板。
- 手机端 `components/settings/UserAccountSection.tsx`：设置页卡片，显示当前账号与账号数，
  点击打开同一个面板。

### 5. 配套改动

- `components/LoginModal.tsx`：手动登录成功后写入账号档案，之后能在面板里切回来。
- 账号按服务器地址分组（`normalizeServer` 归一化后比较），换服务器不会串号。
- 免登录服务器（`localstorage`）打开面板只提示「无需切换账号」。

## 三、验证

- `npx tsc --noEmit`：业务代码 0 错误。
- 新增 `services/__tests__/accountProfiles.test.ts`（6 条用例）：旧账号迁移、新增、同名去重、
  切换、退出、多服务器标记，全部通过。
- 全量单测：75 条中 74 条通过，唯一失败的是历史遗留的 `ThemedText` 快照（与本次改动无关）。
- APK 内 bundle 校验：包含「用户管理」「添加账号」「退出当前账户」「切换」等文案。

## 四、已知限制

- 密码以明文存在 AsyncStorage（与原 `LoginCredentialsManager` 一致），属于本机存储范畴，
  未引入 Keychain / Keystore 加密。多账号后本机保存的密码数量变多，若后续要加固，
  可接入 `expo-secure-store`。
- 账号列表不区分设备渠道，电视端与手机端共用同一份本机数据（同一台设备只装一个端，无影响）。
- 同一服务器下删除服务器的账号需要「退出」，暂未提供「仅移除某个非当前账号」的入口。
