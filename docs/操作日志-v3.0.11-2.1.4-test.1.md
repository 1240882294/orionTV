## 五、发布后发现的两个新问题

### 1. 电视端搜索失败

**现象**：联想出「仙逆」，点搜索提示「搜索失败，请稍后重试」。

**结论**：`/api/search` 8 秒超时（`services/api.ts:111`），服务端聚合 + 253 B/s 弱网共同触发。与本次改动无关（`api.ts` / `search.tsx` 未改）。

### 2. 手机端出画面但暂停、点播放「操作失败」

**现象**：能测速、能出画面，停在暂停态（15:54 / 44:27），点播放弹「操作失败」。

**结论**：`hooks/useVideoHandlers.ts:42-51` 里 `await setPositionAsync(954000)` 与 `playAsync()` 串行且在同一个 try 中 —— seek 慢或失败，`playAsync` 就永远不执行。同时 `useAdFreePlayback` 会先清空 `playUrl` 再回填（`hooks/useAdFreePlayback.ts:62`），导致 `<Video>` 卸载重挂，而 `playerStore.status` 不清空，UI 用残留状态显示「暂停」。点播放时原生播放器尚未 prepared，`playAsync` 抛 `Cannot complete operation because the Video component has not yet loaded`（`node_modules/expo-av/build/Video.js:65-69`），被 catch 成「操作失败」。

**与本次改动的关系**：老隐患，被这次「完整等待」放大触发概率（mount 与 seek 更集中在弱网时刻）。

详见 `/workspace/两个新Bug-原因分析.md`。
