## 一、电视端：搜索框文字只显示一半

### 现象

- 首次进搜索页，打字显示正常；
- 搜完结果、按返回回到搜索页后，输入框里的汉字只剩上半截（截图里的「乡」）；
- 退回桌面重进搜索又正常，但在这个界面再点一次返回，又会被切。

### 根因

`ThemedText` 会给所有文本套一份基础样式：

```
default: { fontSize: 16 * scale, lineHeight: 24 * scale }
scale = useScale() = Platform.isTV ? width / 1000 : 1
```

1080p 电视窗口宽约 960dp → `scale ≈ 0.96` → **基础 lineHeight ≈ 23**。

搜索框的文字样式只覆盖了字号，没有覆盖行高：

```
tvDisplayText: { fontSize: 32, letterSpacing: 2 }   // 行高仍是 23
```

`lineHeight(23) < fontSize(32)`，而 `numberOfLines={1}` 会让 Android 的 TextView
按行盒高度裁切字形 —— 汉字是满格字，下半截直接被切掉。

为什么「打字时看着正常、返回后才明显」：输入拼音时都是拉丁字母，切掉的主要是
`g/y/p` 的下伸部分，不盯着看不出来；而返回后输入框里是整词汉字，满格字被切一半，
一眼就能看出。这也解释了「退出重进又正常」—— 重进后输入框是空的（占位符 26 号字，
切得少），一按返回又把整词带回来，问题重现。

### 改法（`app/search.tsx`）

| 位置 | 改动 |
|---|---|
| `tvDisplayText` | `lineHeight: 44`、`includeFontPadding: false`、`textAlignVertical: center` |
| `tvPlaceholder` | `lineHeight: 36`、同上（26 号字也超过 23 行高） |
| `tvResultTitle` | `lineHeight: 34`（24 号字，结果页标题同样会被切） |
| `tvBackText` | `lineHeight: 30`（22 号字） |
| `tvDisplay` | `height: 76` → `minHeight: 76` + `paddingVertical: 8`，字号变大时盒子跟着长 |
| 输入框两处文本 | `allowFontScaling={false}`，避免电视系统字体缩放把字号顶出行盒 |

## 二、手机端：搜索结果也按剧折叠

之前 `groupByTitle` 只在 `isTV` 分支生效，手机仍平铺 189 张重复卡。

- `groupedResults` 去掉 `isTV` 判断，三端共用；
- 手机/平板列表改用 `groupedResults` + `renderGroupedItem`；
- 列表上方新增一行「x 部 · 共 y 条线路」；
- `VideoCard.mobile` / `VideoCard.tablet` 接 `totalEpisodes`，`> 0` 时角标显示「共 N 集」，
  否则回退源名（其它页面如最近观看、收藏仍显示源名，行为不变）。

跳转没有改：两端卡片都只传 `{ source, q: title }`，`detailStore.init` 走全量搜索，
详情页的线路条数不受影响。
